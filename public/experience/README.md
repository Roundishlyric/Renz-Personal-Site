# Experience photos

Add your three internship photos to this folder using these filenames:

- `internship-1.jpg`
- `internship-2.jpg`
- `internship-3.jpg`

The Experience section shows a "Photo coming soon" placeholder until each file
is available. Refresh the page after adding the photos.

For different filenames or more pictures, update `experiencePhotos` near the top
of `src/app/components/Experience.tsx`. Update each `alt` description to describe
the actual photo. The gallery uses a responsive grid and crops photos to a 4:3 ratio.
